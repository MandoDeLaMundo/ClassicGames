# Unity Programming Playground

A growing collection of classic 2D games recreated from scratch as a long-term software engineering and game development practice project.

Rather than creating a single large game, this repository serves as a personal development playground where I continuously practice programming, software architecture, and professional development workflows while recreating timeless arcade and puzzle games.

The goal is not to perfectly clone the originals, but to use each game to strengthen different programming concepts while building a polished portfolio that demonstrates consistent growth over time.

---

## Purpose

This project exists to accomplish several goals:

* Continue improving my programming skills after graduation.
* Build a public portfolio that demonstrates consistent software development.
* Practice professional workflows used in the game industry.
* Explore different game mechanics and programming challenges.
* Create a personal collection of classic games that can be played without advertisements or internet connectivity.

Every game added to this repository represents another opportunity to learn something new, whether that's AI, collision systems, pathfinding, input handling, rendering, save systems, UI, optimization, or software architecture.

## Why Classic Games?

Classic games are excellent programming exercises because they isolate individual gameplay systems.

Examples include:

* Grid movement
* State machines
* Collision detection
* Enemy AI
* Pathfinding
* Physics
* Input handling
* Animation
* UI systems
* Save data
* Scoring systems

Recreating these mechanics provides focused opportunities to improve programming ability without the complexity of modern AAA production pipelines.
